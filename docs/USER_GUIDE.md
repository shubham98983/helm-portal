# User guide

- **Home** summarizes default-branch CI, pull requests, approvals, AI changes, issues, optional Copilot quality data, and items needing attention. Select a tile or attention link to open its source.
- **Work** groups open and recently closed GitHub issues into Backlog, To do, In progress, Review, and Done. Status labels control open issue placement. Filter by repository, assignee, or label. Initials stand in for avatars.
- **Pull requests** shows the five-column review board. AI badges explain detection; check chips summarize CI; approval text names outstanding reviewers and warns about stale approvals. Leads can request a repository sync.
- **Activity** is a time-ordered feed of pull requests, reviews, checks, workflows, commits, and connected Copilot failure analyses. Filter by repo, actor, and event kind; use Load more for older stored activity.
- **Team** shows reporting lines, responsibilities, supervised AI contributors, and current review/PR workload.
- **Project** describes the configured project, repositories, environments, milestones, policies, and runbooks.
- **Audit** is restricted to leads and reviewers. It shows the advisory verdict for merged AI PRs, review/check evidence, and a CSV export.

The top bar shows the most recent successful or attempted repository sync time. Empty boards are expected when no matching GitHub data is available. A page banner explains GitHub errors such as a missing token, permission failure, rate limit, or inaccessible repository.
